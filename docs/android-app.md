# Nova's Pack on Android: the real app

**What it is:** a small Android app (package `com.novaspack.app`) that opens the live web app full screen, with its own icon, splash screen and no browser bar. Technically it's a Trusted Web Activity, made with Google's Bubblewrap. Because it shows the live site, every web update reaches the app automatically; a new APK is only needed if the Android side changes.

- **Code:** `android/`, generated by Bubblewrap 1.27; target SDK 36, as Google Play requires for new apps from 31 Aug 2026.
- **Build:** `.github/workflows/android.yml` runs free on GitHub and publishes the files on the **android** release.
  - **APK:** https://github.com/novashiv11/novas-pack/releases/download/android/novas-pack.apk
  - **Google Play bundle:** `novas-pack.aab`, only once the stable key exists.
- **Data:** stays on the phone, in Chrome's storage for the site. Uninstalling the app doesn't delete it; clearing Chrome's site data does.

## Setup

**Nothing is needed to get the APK.** Each build signs it with a one-off key. To update the app, uninstall it first and then install the new APK; your data lives in Chrome, so it stays.

**To remove the small address bar at the top** (one tap, once):
1. Open https://github.com/new?name=novashiv11.github.io&visibility=public on your phone.
2. Tap **Create repository**.
3. Tell Claude "done". Claude adds the verification file (`.well-known/assetlinks.json`) with the key's SHA-256 from the release notes.

If GitHub asks whether Claude can access the new repo, allow it.

**Only for Google Play (later):** add the repository secret `ANDROID_KEYSTORE_PASSWORD`, 12+ characters, and keep a copy. Do this in novas-pack → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**. The next build creates a stable key and also makes `novas-pack.aab`.

## Install on an Android phone (anyone)

1. Open the APK link above on the phone, then open the downloaded `novas-pack.apk`.
2. If asked, allow your browser to "install unknown apps", then tap **Install**.
3. Chrome must be installed; it is on almost every Android phone.

Play Protect may warn that the app is from an unknown developer. That's normal for apps outside the Play Store, and the warning goes away once the app is on Google Play.

## Google Play (later; your call, it costs money)

| Step | What | Cost and time |
|---|---|---|
| 1 | Create a Google Play developer account (personal), verify your ID and phone. | $25 once, 1–3 days |
| 2 | Create the app, upload `novas-pack.aab`, and turn on **Play App Signing**. | Free |
| 3 | Add Play's app signing SHA-256 to the verification file. Claude does this; send Claude the fingerprint from Play Console → **Test and release** → **App integrity**. | 5 min |
| 4 | **Closed test:** at least 12 testers opted in for 14 days in a row. This is required for new personal accounts. Ask on Instagram for "12 founding testers". | 14+ days |
| 5 | Store listing: name, short and long description, 512 px icon (`android/store_icon.png`), screenshots (`img/screenshots/`), privacy policy link (`privacy.html`). | 1 hour |
| 6 | Data safety form: **no data collected or shared** (everything stays on the device). Content rating questionnaire. | 30 min |
| 7 | Apply for production; Google reviews it. | A few days |

Sources: [target API level](https://developer.android.com/google/play/requirements/target-sdk). For the 12-tester rule, see [Choicely](https://www.choicely.com/blog/google-play-12-tester-rule) and [Testers Community](https://www.testerscommunity.com/blog/google-play-closed-testing-requirements-2026); check the current wording in Play Console before you start.

## iPhone

The App Store needs an Apple Developer account ($99 a year). On iPhone, Safari → Share → **Add to Home Screen** already opens the app full screen.
